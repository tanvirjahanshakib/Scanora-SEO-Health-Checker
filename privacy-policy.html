Privacy Policy — Scanora

Last updated: July 2026

Scanora is a Chrome extension that analyzes the page you are currently viewing so it can show you an on-page and technical SEO report. This page explains exactly what the extension does and does not do with your data.

What Scanora reads

When you click the Scanora icon, it reads the following from the active tab only, and only while the popup is open:

  • Page title, meta tags, canonical URL, and structured data (JSON-LD)
  • Heading tags (H1–H6) and their text
  • Image elements and their alt attributes
  • Links on the page (URLs and anchor text) to count internal/external/nofollow links
  • Visible body text, used locally to compute word count and keyword density
  • Basic page-load timing from the browser's Performance API

What Scanora does not do

  • It does not send any page content, URL, or analysis result to any server. All scanning and scoring happens locally inside your browser.
  • It does not use cookies, analytics, or third-party trackers.
  • It does not collect personally identifiable information.
  • It does not read pages you have not actively opened the popup on — there is no background browsing history collection.

Permissions explained

  • activeTab / scripting — lets Scanora read the page you're currently looking at, only when you click the extension icon.
  • Host permissions (<all_urls>) — required so the SEO scan can run on any site you choose to check, not just a fixed list.

Changes to this policy

If Scanora adds features that change how data is handled (for example, an optional integration with a third-party SEO data provider), this page will be updated first and the extension's store listing will note the change.

Contact

Questions about this policy can be sent to the developer contact email listed on the Scanora Chrome Web Store listing page.
